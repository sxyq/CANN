# 当前 Dashboard 说明

Dashboard 是状态展示和报告索引，不是实验控制点，不是 Route 选择入口，也不能暂停 Compile、Correctness、Local 或 Online。

版本树只读 `技术路线/技术路线图.md`，结构化版本事实只读 `技术路线/全版本记录.tsv`。Dashboard 不生成第二份版本树，不决定 Route 或 Revision 状态。

## 写入者

Record Owner 是当前 Dashboard 数据和说明的唯一共享写入者。它只消费已经产生的 C2C receipt、正式结果和调度事实；Dashboard 更新异步进行，未更新不影响 Route 执行。

Main 不编辑 Dashboard，Route Agent 和 Support Agent 不编辑 Dashboard，Online Owner 只返回正式结果 receipt。

## 展示内容

Dashboard 可以展示：

- Route、Revision、当前 Candidate 和 Local Best；
- Compile、Correctness、Local、Official 的已记录状态；
- Parent/Candidate 测量摘要和 Local ↔ Official 校准；
- Child 当前动作、下一动作、阻塞事项和 C2C 时间；
- 正式结果路径和历史证据路径。

展示内容必须能追溯到正式记录或 receipt。Local score 不显示为 Official Score；缺失值显示为缺失，不用推测填充。

## 当前数据来源

```text
技术路线/路线成绩表.tsv
技术路线/全版本记录.tsv
调度/当前任务.tsv
调度/本地线上校准.tsv
线上结果/**/result.json
```

`归档/任务看板/` 中的 HTML 是历史或展示产物，不是当前规则入口。未经用户明确要求，不创建自动刷新任务、automation、scheduled task、cron、crontab、at、systemd timer、launchd timer、watchdog 或 detached sleep loop。
