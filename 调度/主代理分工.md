## 5. 权限边界

### 5.1 路线生命周期

| 动作 | Main-1 / Main-2 | Planning / Review Layer |
|---|---|---|
| PARK / CLOSE / ABANDON / MERGE / REPLACE | 不得决定，只报告事实与建议 | 决定 |
| 新增正式 Route / 释放正式 Route slot | 不得决定 | 决定 |
| KEEP / 继续实施 | 只可建议 | 决定 |

### 5.2 Online 三层权限

| 层 | 权限 |
|---|---|
| Main | ONLINE_RECOMMENDATION（WORTHY / NOT_WORTHY） |
| Planning / Review Layer | ONLINE_DECISION（APPROVED / HOLD） |
| Judge Owner | 仅在 APPROVED 后执行正式提交 |

### 5.3 Main 职责

- 阅读和理解完整项目
- 管理自己负责的技术路线组合
- 审查证据、Direct Parent、OFAT
- 组织后续 child agents（仅在 Planning 允许的下一阶段）
- Git / evidence / scheduling
- 汇总 Track-A / Track-B
- 提出路线建议与 ONLINE_RECOMMENDATION

### 5.4 Main 禁止

- 直接写 Candidate Kernel
- 替 Route Agent 做性能实现
- 自行改变路线生命周期
- 自行做 ONLINE_DECISION
- 跨 Main 抢 Route ownership
