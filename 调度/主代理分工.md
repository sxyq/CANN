# 主代理分工

本页记录当前角色说明和信息传递方式。实验状态和成绩以 技术路线/、调度/、本地实验/、线上结果/ 的正式记录为准。

## 工作角色

- Main：汇总任务范围、源码、路线、实验和记录状态。
- Route Agent：处理已有路线的源码、构建、正确性、性能和本地提交。
- Support Agent：整理跨路线资料、群聊、公开资料、硬件和 API 事实。
- Record Owner：维护已有共享 TSV、路线记录和 Dashboard。
- Online Owner：使用已有工具处理用户指定的线上对象。

角色名称用于分工说明，不增加额外的编辑、测试或提交条件。各角色优先沿用已有入口，不创建重复脚本、账本或执行链。

## 资源

server3 的资源参考值为目标 NPU FREE_HBM >= 100 MB。设备负载、AICore、VLLM、其他用户进程、lease 和独占状态作为上下文记录，不形成额外等待或人工确认。

资源不足、真实运行错误、服务器不可连接或可能影响其他用户任务时停止当前操作并保存原因。不停止、杀掉、重启、迁移或修改其他用户任务。

## 本地保存

精确路径分批创建本地提交，保留源码、实验结果、失败材料、凭据和 Git 历史。默认不推送、不创建远端对象、不添加远端审查、自动构建或自动发布配置。没有用户明确要求时，不创建 automation、scheduled task、cron、crontab、at、systemd timer、launchd timer、watchdog 或 detached sleep loop。
