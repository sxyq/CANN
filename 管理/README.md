# CANN 项目管理目录

统一流程见：[统一探索、性能收敛与线上提交流程](../文档/统一探索收敛与线上提交流程.md)；工作区总盘点见 [工作目录盘点](工作目录盘点.md)；阈值配置见 [`config.json`](config.json)；脚本接口见 [`scripts/README.md`](../scripts/README.md)；实际清理留痕见 [清理记录](清理记录.md)。

本目录用于 R001-R029 路线状态、提交队列和跨路线比较。路线 Agent 只维护本路线；主控 Agent 独占全局排行榜和提交队列；唯一 Submission Worker 独占线上提交锁。官方线上分数是性能收敛依据，本地性能数据只用于诊断。

```text
管理/
├── templates/        状态、版本结果和提交任务模板
├── config.json       提交限流、性能收敛和磁盘门禁配置
├── 路线状态/         各路线机器可读状态
├── 提交队列/         唯一线上提交队列
├── 跨路线比较/       路线摘要、排行榜和全局 Champion
└── 清理记录.md       清理前后空间和删除目标记录
```
