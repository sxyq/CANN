# 线上提交规范

本文件是 Online 角色链和正式结果处理的唯一说明。本轮 Online 工作由 `cann-online-owner` Skill 执行；本文件不复制成绩。

## 当前授权范围

当前用户明确授权 `ONLINE_AUTHORIZATION_SCOPE=W4_BEST_OF_ROUTE_VALIDATED_CANDIDATES_ONLY`：每条现有 W4 Route 最多正式提交一个已验证的路线内最佳 Candidate。范围内无需另等逐 Route Planning 批准；这项授权不代表任何具体 Route 已通过资格。超出 W4 现有路线、每 Route 一次的额度或本授权对象范围，须另获明确授权。

## 角色链

```text
Route Agent validated result
→ Main evidence summary
→ Online Owner qualification and formal Judge submit
→ Record Owner asynchronous record
```

- Route Agent 不正式提交 Online。Main 只整理并传递事实，不直接提交。
- Planning / Review Layer 管理授权范围外的 Online 决策。
- Online Owner 是当前授权范围内唯一正式 Judge submitter。

## 送 Online 的证据包

Main 向 Online Owner 提供：

- starting local measurement context；
- current local best；
- 每个小变化的 Local gain；
- cumulative local gain；
- Correctness status；
- experiment count；
- Local 与历史 Official 方向信息；
- 同一 Route 内候选的可比性与路线内最佳候选依据；
- 失败和负结果是否完整保留。

候选只依据同一 Route 内可比的有效 Local 结果确定。比较时核对 shape、dtype、runner、计时边界、设备条件和采样方法一致；不同 shape 的跨 Route Local 百分比不得混排。各 Route 分别判断，不为凑数提交；本轮规则不预列具体 eligible Route 名单。

## 提交资格

每次正式提交前，Online Owner 必须同时确认：

1. 对应 Candidate 的 Build（Compile）为 `PASS`；
2. 对应 Candidate 的 Correctness 为 `PASS`；
3. Local 按 `本地性能测试规范.md` 判定有效，并具备该规范要求的 numeric score/delta、Parent/Candidate raw samples 与 medians、shape/dtype、device、free HBM、load note 和 current best；
4. 候选由本 Route 的可比有效 Local 结果独立选为最佳；
5. 实际 Judge 提交源码与 Build、Correctness、Local 所验证的 Candidate 源码完全一致，并核对、记录对应 Git commit ID；
6. 尚有该 Route 每 Route 一次的授权额度，Judge 当前仍有可用提交额度，且已确认当期 Judge 规则。

以上条件须全部成立。任一项缺失、失败或无法确认，该 Route 记为 `NO_ELIGIBLE_SUBMISSION`，不提交，不借用其他 Route 的候选凑数。实际 Judge 载荷须逐文件对应到已验证提交里的源码；提交过程中 Candidate 有变化或对应关系无法确认时，不提交。

## 正式提交与结果

符合全部资格后，Online Owner 使用现有正式提交工具提交一次，返回 Submission ID、PASS/FAIL/INCONCLUSIVE、Official Score 和 Official delta。正式结果写入 `线上结果/<ROUTE>/<REVISION>/`，共享成绩和校准由 Record Owner 异步更新。Route Agent、Main、Record Owner 均不执行正式提交。

历史证据中的旧字段保持原样。若提交工具内部仍产生摘要元数据，记为 `TOOLING_REMAINDER`；工作流不读取、不计算、不以该字段作为提交依据。

## Local ↔ Official

每次正式结果都向 Record Owner 发送 Online receipt，由其更新 `调度/本地线上校准.tsv`：

```text
ROUTE
REVISION
LOCAL_CONTEXT
LOCAL_DELTA
OFFICIAL_SCORE
OFFICIAL_DELTA
DIRECTION
SHAPE / DTYPE
MEASUREMENT_NOTE
DECISION
```

Local score 不替代 Official Score；线上失败不清除既有 Local Best 和失败证据。

## 提交安全

禁止 Route Agent 或 Main 提交、重复提交或并发提交同一 Candidate，也不得在 server3 上提交、突破每 Route 一次的授权额度，或提交未满足全部资格的 Candidate。未经用户明确要求，不创建 automation、scheduled task、cron、crontab、at、systemd timer、launchd timer、watchdog 或 detached sleep loop。
