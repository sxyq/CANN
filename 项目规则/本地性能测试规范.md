# 本地性能测试规范

本文件只描述 Local measurement method，不规定额外的实验资格流程。Correctness 仍然在 Local 之前，因为项目执行顺序固定为：

```text
ONE CHANGE → COMPILE → CORRECTNESS → LOCAL → RESULT
```

## LOCAL SCORE REQUIRED

正常 Local 结果必须提供 numeric Local score 和 numeric Local delta、Parent/Candidate raw samples 与 medians、shape/dtype、device、free HBM、load note 和 current best。样本不足、负载较高或结果未改善时保留已有 raw data，并报告实际状态；没有执行 Local 时使用 `LOCAL_SCORE=NONE`，不得补造数值，也不得开启下一普通 Revision。Local 结果进入 `RESULT → COMMIT → VERSION_RECORD_EVENT`，并受 `VERSION_RECORD_EVENT REQUIRED` 和 `NEXT REVISION BLOCKED UNTIL PREVIOUS EVENT EXISTS` 约束。Local-only stacking 不构成 Official 验收依据。

## 资源准入：Local 不要求独占设备

Local 的执行条件与 Compile、Correctness、Profile 完全一致：

```text
FREE_HBM >= 100 MB
→ RUN_LOCAL
```

即使当前负载较高也执行 Local，并记录负载上下文。`FREE_HBM >= 100 MB` 是测量准入，`DEVICE_LOAD`、`AICORE_LOAD`、`OTHER_PROCESS_PRESENT`、`LOAD_NOTE`、`LOAD_QUALITY` 和 jitter 都是**测量解释字段**，不是测量准入字段。

禁止 `LOAD_HIGH → SKIP_LOCAL` 这类推导。正确语义是：

```text
LOAD_HIGH + FREE_HBM >= 100 MB → RUN_LOCAL → record load context
```

## 测量目标

每次 Local 都尽量提供可复核的 Parent/Candidate 比较：

- 多次 samples；
- 每次 raw latency；
- `device_us` 与需要时的 `wall_us`；
- Parent latency、Candidate latency、Local delta；
- median、mean、stdev、CV、min、max、MAD、p10、p90 等 jitter 信息；
- 开测前后 device load、HBM、AICore 和进程快照；
- shape、dtype、runner、warmup、repeat 次数和执行顺序；
- repeatability 观察和异常原因。

这些内容是测量信息，不是实验开始条件。样本不足或负载影响结果时，保留已取得的 raw data，把负载情况写入 `LOAD_NOTE` / `LOAD_QUALITY` 作为解释依据，而不是放弃测量。只有 `FREE_HBM < 100 MB`、真实 OOM / allocation failure、任务会破坏其他用户任务或server3 不可连接时才停止；停止时报告原因和 `LOCAL_SCORE=NONE`，由 Route Agent 回到当前 Local Best 再选择下一项小变化。

## 推荐方法

1. Parent 和 Candidate 使用相同 shape、dtype、runner、计时边界和设备条件；
2. warmup 和数据搬运放在计时样本之外；
3. 分配、释放和 host realloc 不放入计时循环；
4. 优先使用 device event，同时保留 wall-clock 作为诊断信息；
5. Parent/Candidate 交错采样，避免把两个时间段的负载差异误认为性能差异；
6. 永久保留 raw samples，不按结果方向删除样本或临时改变离群点处理；
7. 记录原始数据路径、统计摘要、Local delta、jitter 和设备负载。

## Parent / Candidate 报告

报告至少包含：

```text
ROUTE
REVISION
PARENT
SHAPE / DTYPE
METHOD
SAMPLE_COUNT
PARENT_RAW_LATENCY
CANDIDATE_RAW_LATENCY
PARENT_MEDIAN
CANDIDATE_MEDIAN
LOCAL_DELTA
JITTER
FREE_HBM
DEVICE_LOAD
AICORE_LOAD
OTHER_PROCESS_PRESENT
LOAD_QUALITY
REPEATABILITY
LOCAL_SCORE
INTERPRETATION
```

`FREE_HBM` 是准入事实，`DEVICE_LOAD`、`AICORE_LOAD`、`OTHER_PROCESS_PRESENT`、`LOAD_QUALITY` 和 `JITTER` 是解释字段。负载字段只用于解释测量结果，不用于决定是否测量。

测量结果不改写 Official Score。Local 与 Official 的对应关系由 `调度/本地线上校准.tsv` 记录。

## 资源与停止位置

设备选择按 `FREE_HBM >= 100 MB`，服务器操作与安全见 `服务器实验规范.md`。Local 不要求独占设备，AICore、VLLM、其他用户进程、device load、lease 和 exclusive authorization 都不是 Local 的停止条件。不要等待某个固定百分比、固定次数或固定时间间隔，也不要创建后台轮询任务。
