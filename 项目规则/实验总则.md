# 实验总则

本文件是项目治理与角色边界的唯一说明。具体执行顺序、测量方法、服务器安全、Git 和 Online 分别见同目录对应文件；Route Agent 的实际循环以 `.agents/skills/cann-route-executor/SKILL.md` 为准。

## 项目目录

```text
项目规则/     当前主题规则
.agents/skills/角色 Skill  当前角色行为
技术路线/     Route、Revision、成绩和血缘事实
调度/         当前任务与 Local ↔ Official 事实
本地实验/     Local 证据
线上结果/     Official 结果
研究/         研究和假设材料
归档/         历史资料，只作证据参考
```

成绩与状态只能从正式记录读取，不凭聊天记忆改写。历史目录和旧证据保持原样，不重新成为当前入口。

## Route 生命周期

Planning / Review Layer 负责路线池、Route 新建、继续、暂停、PARK、CLOSE、REPLACE、MERGE、Route slot 和 Online decision。Main、Route Agent、Support Agent、Record Owner、Online Owner 只能报告事实和建议。

## 角色边界

| 角色 | 负责 | 明确不负责 |
|---|---|---|
| Main | Child 生命周期、C2C 收集、并发协调、偏离识别、向 Planning 汇报 | 直接读写项目文件、Candidate、TSV、Dashboard、Git、实验命令、身份计算 |
| Route Agent | 一个 Route 的 Candidate、Compile、Correctness、Local、版本 Git | 其他 Route、共享记录、Route 生命周期、正式 Online |
| Support Agent | 跨 Route 研究、群聊/公开资料/硬件/API 取证 | Candidate、Route ownership、共享记录、正式 Online |
| Record Owner | 共享记录和 Dashboard 的唯一写入 | Candidate、实验、Route 决策、执行控制 |
| Online Owner | Planning 批准后的唯一正式 Judge submitter | Candidate、Route 决策、共享成绩写入 |

Route ownership 固定为：

```text
1 Route = 1 Agent = 1 Context = 1 Branch = 1 Worktree
```

## 实验主链

```text
ONE CHANGE → COMPILE → CORRECTNESS → LOCAL → RESULT → COMMIT → NEXT CHANGE
```

每个 Revision 只包含一个小技术变化。Compile 失败只处理 Compile 问题；Correctness 失败只处理 Correctness 问题。每次 Local 结果都独立报告，Local 改善才更新 `CURRENT_LOCAL_BEST`。

记录由 Record Owner 异步写入，不能成为实验开始、Compile、Correctness、Local 或 Online 的前置条件。失败、负结果、工具失败和未完成结果均保留。

## 结果分离

- Local score 只表示本地测量；Official Score 只来自正式 Judge 结果；
- `技术路线/全版本记录.tsv` 保存 Revision 事实；
- `技术路线/路线成绩表.tsv` 保存 Route 和 Overall 成绩；
- `调度/本地线上校准.tsv` 保存 Local 与 Official 的方向和幅度比较；
- `本地实验/` 和 `线上结果/` 保存对应证据。

## 安全边界

禁止 force push、reset、clean、历史改写和删除失败证据；禁止杀、暂停或迁移其他用户进程、服务、数据和设备任务；禁止多个写入者同时修改同一 Route。未经用户明确要求，不创建 automation、scheduled task、cron、crontab、at、systemd timer、launchd timer、watchdog 或 detached sleep loop。

Main 不把 Dashboard 当作执行控制点，Route Agent 不直接正式提交 Online。
