# 执行约定

本文件是工作流索引页，不重复 Route 执行正文。实际 Route 循环见 `.agents/skills/cann-route-executor/SKILL.md`；角色边界见 `实验总则.md`。

## 唯一执行顺序

```text
ONE CHANGE
→ COMPILE
→ CORRECTNESS
→ LOCAL
→ RESULT
→ COMMIT
→ NEXT CHANGE
```

一个 Revision 只表达一个小技术变化。这个约束直接作用于版本内容，不另设审核阶段。Local 改善可以连续积累，但每一步都必须完成上面的完整顺序；多个独立变化不得合并到一个 Revision。

## Route 与 worktree

```text
1 Route = 1 Agent = 1 Context = 1 Branch = 1 Worktree
```

Route Agent 只读写自己的 Candidate 和证据，不读取其他 Route worktree，不写共享 TSV 或 Dashboard。Main 只通过 C2C receipt 协调，Record Owner 是共享记录唯一写入者。

## 阶段处理

- Compile 失败：只处理 Compile 问题，再次 Compile；
- Correctness 失败：只处理 Correctness 问题，保留失败证据；
- Local 结果：保留 raw samples、Parent/Candidate 比较、delta、jitter、device load 和 repeatability；
- 负结果：提交并保留，不提升为 Local Best；
- 改善结果：提交、及时 push，并成为当前 Local Best 的候选。

Build Fix 或 Correctness Fix 不得顺手加入新的性能变化。没有可用 Local 结果时记录原因和 `NONE`，不把它写成零收益，也不删除版本。

## 证据位置

```text
本地实验/<ROUTE>/<REVISION>/   Local 证据
线上结果/<ROUTE>/<REVISION>/   Official 证据
研究/<ROUTE>/                  研究材料
技术路线/全版本记录.tsv        Revision 事实
```

旧实验目录中的字段和结论保持不动。正式记录由 Record Owner 根据 C2C receipt 异步同步。
