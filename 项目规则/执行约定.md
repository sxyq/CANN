# 执行约定

本文件只保留当前本地实验、记录和 Git 工作所需的事实。旧路线与旧回执留在历史目录，不恢复成当前执行链。

## 当前工作

- Main 负责需求范围、路线协调和结果汇总。
- Route Agent 负责已有源码和实验目录。
- Record Owner 负责已有共享记录。
- Support Agent 负责资料和 API 研究。
- Online Owner 使用已有提交工具处理用户指定的对象。

## 实验记录

每个变化写清路线、版本、父版本、源码位置、实验命令、返回码、设备、负载、结果和停止原因。成功、失败、未执行和负结果都保存原始证据；没有数据就写 NONE 或 UNKNOWN，不补造数值。

验证项目按用户任务和实际影响选择，未执行项目直接记录。

## 工作树与数据

- 不覆盖其他路线的未提交文件。
- 保留 Git 历史、凭据、SQLite、Keychain、LaunchAgent、运行缓存、实验结果和失败材料。
- 不使用 reset --hard、clean、force push 或历史改写。
- 共享 TSV、Dashboard 和归档资料沿用已有位置，不创建重复账本。

## Git 与资源

按 项目规则/Git工作流程.md 分批本地提交，只用精确路径暂存，不纳入用户已有的无关改动。服务器安全、用户进程保护、设备资源和凭据规则见 项目规则/服务器实验规范.md。

没有用户明确要求时，不创建 automation、scheduled task、cron、crontab、at、systemd timer、launchd timer、watchdog 或 detached sleep loop。
