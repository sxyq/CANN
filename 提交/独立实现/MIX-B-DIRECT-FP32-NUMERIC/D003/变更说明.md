# D003

## Hypothesis

对每次 GM 到 UB 的输入搬运显式按 32B 对齐补零，计算阶段仍只消费有效元素；这样尾块不会依赖未定义填充值，预期降低非对齐 D 导致的运行时异常和尾部数值污染。

## Scope

- 只实现 `MIX-B-DIRECT-FP32-NUMERIC`。
- 相比 D001 只改变 `DataCopyPad` 的输入尾块处理。
- 保持 FP32 中间计算、Sqrt、向量除法和 `CAST_RINT` 输出。
- 本候选不进行本地 NPU 正确性、profiling 或 benchmark。

## Compile target

- CANN: 服务器项目内 `cann-9.0.0` 工具链
- SoC compile flag: `dav-2201`
- Compile-only acceptance: `compile PASS`
