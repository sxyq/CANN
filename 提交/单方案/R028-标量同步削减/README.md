# R028 标量同步削减

## 路线定位

本目录保存减少 `GetValue`、事件等待和逐 tile 标量回读的实验。它是归约和流水的性能优化轴，可与 `R007-ReduceSum`、`R011-手工向量归约`、`R015-多行合并DMA` 组合。

## 历史来源

- 汇总2：`调研/归档/汇总2/技术路线总报告.md` §5 的 `R006 标量同步削减`。
- 汇总1：相关内容分散在两遍/单遍、ReduceSum 和路线组合章节，作为同步次数变体出现。
- 汇总3：相关内容分散在归约和多行合并 DMA 说明中，未单独编号。

## 主要变体

1. 每行归约结束后只做一次标量读取。
2. 多行合并归约结果，减少 `GetValue` 次数。
3. 用向量广播和本地结果消费替代频繁标量读回。
4. 评估 SPR 读取时必须以目标 CANN/SoC 的官方支持为准，不能因其他架构存在 API 就直接采用。

## 提交与实验状态

- 提交资格：可作为已有 Kernel 的性能组件，不单独代表完整算子实现。
- 当前状态：设计级，未完成真实 NPU 性能测量。
- 每个版本必须同时记录归约方式、事件顺序、同步次数、精度结果和端到端耗时。
