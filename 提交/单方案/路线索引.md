# 单方案路线索引

每条路线目录只在形成独立候选时创建 `V001`、`V002` 等版本目录。三份汇总的原始编号存在语义错位，当前目录以技术思想为统一编号；完整的跨报告映射见 `../../调研/总结.md`。所有版本实验和平台分数统一记录在 `../版本实验记录.md`。

目录中的路线分为四种用途：可进入 Kernel 的实现组件、性能优化轴、否决或研究参考、验证与提交支撑。建立目录表示资料和实验位置存在，不表示该路线可以单独上传。
