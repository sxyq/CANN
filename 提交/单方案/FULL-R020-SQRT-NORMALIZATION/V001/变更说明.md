# FULL-R020 V001

本候选围绕 FP32 `Sqrt` 归一化组织。第一遍按 4096 元素 tile 形成 `x + residual` 并使用独立 FP32 reduction workspace 累加平方和；随后执行 mean、epsilon 和向量 `Sqrt`。第二遍重新读取输入，在 FP32 中用重复分母向量完成除法，再完成 gamma、bias 和 `CAST_RINT` 输出。

本路线没有引入 retained-y、参数驻留、宽行缓存、多行 DMA、手工 tail、row-group 调度或集成多模式分发。GM/UB 搬运使用 `DataCopyPad`，尾块只写有效字节。

验收顺序：源码静态核对 -> CANN 编译 -> FP16 D=64 rows=1 最小运行 -> FP16 非 32B 尾块 -> 其余快速探针。任何失败均保留日志，不叠加第二个算法改动。
