# FULL-R027-GPU-MIGRATION-REFERENCE V001

## 路线与实现

R027 将 GPU/Triton 的 row-resident fused 数据流映射为 Ascend C UB 数据流：`D <= 8192` 时，第一遍把 FP32 `y = x + residual` 写入 `valueFp32_[col]`，归约只读取同一份 UB 数据；RMS 得到后，第二阶段直接消费这份 `y`，加载 gamma/bias 并完成 epilogue，省去第二次 x/residual GM 搬运。更宽的行保留分块两遍路径，避免超出 UB。
