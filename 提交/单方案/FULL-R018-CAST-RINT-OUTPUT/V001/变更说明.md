# FULL-R018 V001

本候选围绕低精度输出的 `CAST_RINT` 和输出缓冲区所有权组织。第一遍在 FP32 中完成加法、平方和归约，第二遍在 FP32 中完成归一化、gamma 和 bias；FP16/BF16 结果统一经过独立的 native output staging buffer，再用 `CAST_RINT` 写回 GM。

本路线没有引入 retained-y、参数驻留、宽行缓存、多行 DMA、手工 tail、row-group 调度或集成多模式分发。GM/UB 搬运使用 `DataCopyPad`，尾块只写有效字节。

验收顺序：源码静态核对 -> CANN 编译 -> FP16 D=64 rows=1 最小运行 -> FP16 非 32B 尾块 -> 其余快速探针。任何失败均保留日志，不叠加第二个算法改动。
