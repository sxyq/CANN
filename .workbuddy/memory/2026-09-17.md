**已实测的接口事实（匿名 GET，无需登录态）**
- `GET /api/submissions/{id}` → 200 公开可读；不存在的 id 返 404 而非 401 ⇒ 该路由无登录门。响应含 `status / valid / result[] / can_view_code / files`，**没有总分字段**。
- `result[]` 每项：`testcase_id / time(μs) / precision_ratio(匹配率) / testcase_status / best_time / type / msg`；`result[].score` 恒为 0（未填充）。
- `GET /api/problems/name/addrmsnormbias` → problemId `6a9a9a99bf41025d6013eb85`、ID 1742、`code_template=npu_kernel_dev`、15 个测试点公开 `tbest`。
- `GET /api/problems/{pid}/ranking?page=&size=` → 公开；rows 含 `submission_id / status / score(官方总分) / result[]`，顶层 `testcases[]` 含 15 项 tbest。**只收录 Pass 提交**（首页 100 条全 Pass）。
- `GET /api/submissions/user/{uid}/problem/{pid}` → **401 请先登录**（用户维度读需要登录，单条读与排行不需要）。

**已复现平台评分公式**
用公开样本 `6aaa74eeb0477ec41e147510`（官方 score 74.41）的 15 点 time 与排行 tbest 代入 `s_i = 100/(1+log₁.₅(tᵢ/Tᵢ))` 取均值 = **74.411**，与官方一致；且该提交 `result[].best_time` 与排行 `testcases[].tbest` 15 项逐项相等。⇒ 单条提交接口即可完整复算总分，`tbest` 即公式中的 `T_i`。复算值仅作诊断，收敛仍只认排行榜官方分。
