# Host 层数值验证记录（无 NPU 环境，2026-09-10）

> 性质：**辅助验证**。验证对象是 `op_kernel` 的算法语义（FP32 归约 + 分块 + 尾块补 0 + 输出一次性量化），
> 以 `reference_verify.py` 在 CPU 上模拟。脚本先分别量化 x、residual、gamma、bias，再计算公式，避免把输入相加后才量化造成语义偏差。
> **本记录不构成任何 NPU 编译/精度/性能已通过的声明**（仓库规则 6）。

## 1. 验证内容

- 数据：dtype × {fp32, fp16, bf16}；rank × {2D, 3D, 4D}；D × {64,67,96,129,192,255,576,1000,1024,2048,4096,8192,32768}；共 117 组。
- 输入分布：x~N(0,0.8)、r~N(0,0.4)、gamma=1+N(0,0.2)、bias=N(0,0.3)、eps=1e-5。
- 参考：① 原始输入的 fp64 数学参考，用于观察输入/输出 dtype 的量化误差；② 已量化输入的 fp64 公式参考；
  ③ 已量化输入的 fp32 公式参考，用于观察 FP32 归约顺序差异。

## 2. 结果汇总

| 口径 | fp32 | fp16 | bf16 |

| 原始输入 fp64 参考（信息列） | max_abs 9.54e-7 | max_abs 4.52e-3 | max_abs 3.39e-2 |
| 已量化输入 fp64 参考（本地诊断） | 39/39 | 39/39 | 37/39 |

两组未通过均为 BF16、D=32768：`3D` 与 `4D` 各 1 组，最大绝对差分别为

不能据此推断真实判题结果。题面误差公式和平台参考路径仍需在真实 CANN/NPU 上确认。

## 3. 算法语义核对结论

- 公式、归一化轴（最后一维）、eps 位置（sqrt(mean+eps)）、gamma/bias 广播 (D,)：与题面一致。
- 尾块模拟（DataCopyPad 补 0 语义）：D 非 32 倍数（67/129/255/1000 等）结果连续无跳变。
- FP32 内部计算 + 末尾单次量化：FP32 39/39 组通过本地诊断，最大绝对差为 `9.54e-7`；
  结果支持继续采用 FP32 归约，但不代替真实设备验证。

## 6. 第二轮 CPU 同链验证（2026-09-11，Agent06）

> 脚本在 /tmp/agent06_numerics/（exp1_main.py / exp2_fix.py / exp3_chunk.py），依赖 numpy≥2.0 + ml_dtypes，seed 固定可复现；不入仓库。结论为 CPU 参考，**不构成 NPU 精度声明**。

- **判题语义确认（A/B，读模板源码）**：golden = 输入各自量化 → FP32 内部计算 → cast 回原 dtype；判定 = `np.isclose(rtol=0.001, atol=0.001, equal_nan=True)` 逐元素 + 失配 ≤0.1%。同链计算可逐位一致。
- **fp16：必过**（1 ulp=9.77e-4 < 1e-3，实验 mismatch 恒 0）；**fp32：必过**（1e-4 容差余量 ~100 倍）。
- **bf16：唯一风险**，两条硬约束：
  1. 归约必须分块/树形：整行顺序累加 D=32768 实测 mismatch 0.16% > 0.1% 判挂；分块 ≤4096 后 0.002~0.010% 安全。
  2. sqrt 必须正确舍入：裸 rsqrt 误差 2^-14 时 mismatch 0.4~1.2% 全挂；误差 ≤2^-20（或向量 Sqrt 0 ulp）才安全。
- **fp16 域累加 y² 必溢出**（|y|≥256 单步 inf）——低精度中间方案直接否定。
- **CAST_RINT = RNE**（A 级规则文档），与 numpy cast 一致；中间 Cast 时机必须与 golden 同链（S8 案例：全程 fp32 反而对不上 bf16 中间结果）。
- **建议 Kernel 计算链**：`Cast(CAST_NONE)→Add(fp32)→Mul 平方→分块 ReduceSum(≤4096)→块间标量合并→Muls(1/D)→Add(eps)→Sqrt(向量)或正确舍入 rsqrt→Muls(1/rms)→Mul(gamma fp32)→Add(bias fp32)→Cast(CAST_RINT)`。
- 测试矩阵（dtype×rank×D{1,31,32,33,64,127,128,129,1024,4096,32768}×outer 三档 + 边界格）见 `Agent06-numerics.md` §4。
