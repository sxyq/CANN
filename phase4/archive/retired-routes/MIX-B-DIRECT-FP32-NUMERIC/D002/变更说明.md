# D002

## Hypothesis

将每个 1024 元素块的 FP32 平方和写入 8 字节对齐的 partial slot，并在 Vector 域合并；整行只在归一化前读取一次标量，预期减少逐块标量读取带来的舍入累积和可见性风险。

## Scope

- 只实现 `MIX-B-DIRECT-FP32-NUMERIC`。
- 相比 D001 只改变平方和跨块的合并方式。
- 使用 `__global__ __vector__` 直调入口和 `DataCopyPad`。
- 本候选不进行本地 NPU 正确性、profiling 或 benchmark。

## Compile target

- CANN: 服务器项目内 `cann-9.0.0` 工具链
- SoC compile flag: `dav-2201`
- Compile-only acceptance: `compile PASS`
