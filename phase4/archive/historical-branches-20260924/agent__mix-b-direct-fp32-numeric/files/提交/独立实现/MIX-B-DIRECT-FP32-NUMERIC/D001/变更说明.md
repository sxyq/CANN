# D001

## Hypothesis

固定 1024 元素块的两遍扫描路径可以在控制代码体量的同时保持数值链稳定：输入和残差先转 FP32，在 FP32 中完成加法、平方和、均值、epsilon、Sqrt、向量除法、gamma 与 bias，输出只做一次 `CAST_RINT`。

## Scope

- 只实现 `MIX-B-DIRECT-FP32-NUMERIC`。
- 使用 `__global__ __vector__` 直调入口。
- 使用 `DataCopyPad` 处理输入和输出搬运。
- 本候选不进行本地 NPU 正确性、profiling 或 benchmark。

## Compile target

- CANN: 服务器项目内 `cann-9.0.0` 工具链
- SoC compile flag: `dav-2201`
- Compile-only acceptance: `compile PASS`
