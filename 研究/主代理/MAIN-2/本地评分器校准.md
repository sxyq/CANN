## 3. 对 evaluator 的含义（暂不改主评估器）

1. **单形状 / 小幅度本地胜不能触发高置信 Online。** ASYNC 虽然多形状同向，幅度 1–3% 对 15-case 均值贡献被噪声与非目标 case 吃掉。
2. **p10 同向比 median 更稳，但仍不是 Official 代理。** ASYNC p10 12/12 同向，Official 仍低于 anchor。
3. **需要形状加权**：Official 弱 case（14/7/1/6/4/8）与本地探针形状的映射仍是盲区。没有官方 shape map 时，wide LP 胜不等于 case 14 胜。
4. **阈值建议（供 Planning，非正式变更）**：进入 Online 前建议要求「≥2 形状同向 **且** 覆盖与弱 case 对应的形状族 **且** 幅度或累计改善可解释弱 case 分数」。

## 4. SERVER_EVALUATOR_CANDIDATE_V1（草案，不启用）

- 变更点：引入弱 case 形状族覆盖检查 + 幅度下限（按噪声底，不按固定 %）。
- 状态：`SHADOW_ONLY`，不替代 canonical。
- 触发条件：再积累 2–3 个同模式样本后做历史 replay（route ranking / 方向正确率 / FP / FN / shape/dtype weighting）。
- 正式替代须 Planning Review。

## 6. 测量装置偏置（2026-09-28 新增）

COEFF V004 控制组实验发现：**1x32768 两 binary 路径完全相同时，仍出现 −2.77% favC（5/6）**。

- 含义：该 harness 存在 candidate 侧偏置；判定 <3% 小收益前必须减控制底或做 null-binary 对照（parent-rebuild vs parent）。
- 影响：ASYNC V001 的 1–3% 本地胜、MULTIROW V002 的 −2%、COEFF V004 的 1x6144 残留，均需按此重估置信度。
- 短 kernel（~5–6µs）配方：warmup≥60、samples≥81、sb blocks≥3。
- 处置：不改主 evaluator；将 null-binary 对照列为可选工具，是否授权由 Planning 决定。
