## 精度与统计

reference 继续使用原 CPU FP64 公式，最终转 FP16；epsilon、舍入和容差均不改。
atol=rtol=0.001，允许失配比例=0.001，所有值须有限。原四个输入按
16x16384、8x16384、16x32768、16x16352 顺序，每侧严格超差数为 1/0/3/0，
双侧均按原模板通过，P/C 逐位相同；本次不会重跑这四项 Candidate reference。
本次 P/P 在采样前与采样结束时验证已声明的两个输入，保留严格计数。

按 device、stream、task ID 对应 op_summary 与 task_time，结合实际 kernel 顺序，
区分 correctness、warmup、timed。为每个 timed call 记录实际设备输出指针、槽位、
先后位置、组号、pair 号、事件 task ID、kernel 名称和 task 时间边界。
核对 kernel 是否处于相邻 EVENT_RECORD 之间；保留 ACL elapsed 与事件时间戳间隔的差。

两种计时范围均保留所有样本。报告各侧、合并、各组、各位置与 PC/CP 次序的 median、
MAD/median、mean、stdev、CV、p10/p90、最小/最大、逐对差和中位数比。
沿用 MAD/median <= 0.10、各组中位数对双侧合并中位数的最大相对偏移 <= 0.10；
同时要求 P/P 接近零，不能单靠中心稳定就宣称可分辨小收益。

```text
MEASUREMENT_FLOOR=max(p90(abs(P2-P1)), range(group medians))
OLD_TARGET_OBSERVED_GAP_US=0.06
OLD_TARGET_OBSERVATION_ONLY_DELTA_PERCENT=-0.24916944038974043
```

目标约 0.06 us 来自原观察值，不视为已确认收益。配对噪声若高于该幅度，或原中心
要求不满足，记录 MEASUREMENT_BLOCKED，Candidate 不运行，LOCAL_SCORE=NONE。
没有可信 P/P 时不为取得 Candidate 数字追加采样。跨设备、旧窗口与本次数据不合并。
即使中心条件满足，仍须完整报告长尾、位置差异、reference 与所有对应关系。

本次输出仅为研究与 V001 同版事件；有效 Local 数和连续无改善贡献均不增加。
未知的 kernel 内部原因继续写 UNKNOWN；不把 event 减 task 全部归给某一种 host API。
