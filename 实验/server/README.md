# server — 服务器侧证据

存放实验服务器上的编译、正确性与性能原始日志。

## 预期布局

```text
实验/server/
└── V005/
    ├── 编译日志（完整编译、增量编译等）
    ├── 正确性日志（三 dtype 矩阵、D 边界、BF16 用例对照、完整正确性复核等）
    ├── 性能日志（完整性能、性能校准、msprof 数据等）
    └── 脚本与辅助文件（gen_data、verify、probe 套件等）
```

`server/V005/` 的内容来自 `临时/服务器证据/V005/` 的迁移（迁移由清理流程中的其他 Agent 执行）。V005 属于 H001 混合方案实验轨道，**不是** FULL 线上主线；其服务器验证结论见该目录日志与 `提交/混合方案/H001-正确性优先/V005/结果.md`。

后续每条路线在服务器产生的证据，按 `实验/server/<版本或路线>/` 另建子目录，与 V005 分开。
