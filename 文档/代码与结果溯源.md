## 未绑定项（当前事实）

- 绝大多数官方分数**没有绑定 submission id**。
- 所有官方分数**都没有绑定 git commit**（分数产生于线上提交时刻，当时未做 commit 绑定）。
- R029-V003 的双 SHA 冲突（沙箱 `aebe961d…` vs 对话重建 `b1470ef5…`）保持未裁决状态，本文件只登记，不判定哪个是真实提交载荷。
- 后续按 [实验纪律](实验纪律.md)：新提交从候选起就绑定 源码 SHA-256 + git commit + submission id，三件套缺一不可；存量历史分数的绑定缺口不再倒推修补。
