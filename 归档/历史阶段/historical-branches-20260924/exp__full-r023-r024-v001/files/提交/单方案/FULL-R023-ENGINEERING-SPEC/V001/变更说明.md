# FULL-R023 V001

本版本把工程规范作为可提交实现的主张：直调入口完整保留，所有行和字节偏移使用 `uint64_t`，输入参数、dtype、rank、shape 和乘法溢出在 host 入口拒绝，尾块只搬运有效字节，设备侧同步点集中在显式 helper。

源码是完整可提交的 `kernel.txt`，核心 `x + residual`、平方、归约、epsilon、开方、归一化、gamma 和 bias 仍全部在 Ascend C kernel 内执行。该路线不使用 CPU 结果替代设备输出。

验收：源码静态核对、CANN 9.0 编译、FP16 单行最小运行。完整线上提交由主调度 lane 负责。
