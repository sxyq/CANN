# FULL-R024 V001

本候选把 CPU 矩阵覆盖的搬运边界落实到设备代码：FP32 使用 2048 元素 tile，FP16/BF16 使用 4096 元素 tile；当源地址和有效字节数都满足 32 字节对齐时走 `DataCopy`，其余输入、参数和输出片段走 `DataCopyPad`。矩阵包含对齐边界、跨 tile、跨行地址、尾块、FP16/BF16/FP32、2D/3D/4D、不同 outer、epsilon 和特殊值。

数学链路保持完整：`x + residual`、平方、最后一维归约、epsilon、开方、归一化、gamma 和 bias 均在 Ascend C kernel 中完成，CPU 脚本只生成独立参考结果和搬运路径统计，不向设备输出供数。

最小验收顺序：CPU 矩阵 -> 候选源码 SHA-256 -> 服务器 CANN 编译 -> 可用 NPU 时执行最小用例。没有可用 NPU 时保留 compile-pass 和资源状态，不把运行状态写成已完成。
