# D005

## Hypothesis

在 `ReduceSum` 写入结果后、读取标量结果前显式加入 `HardEvent::V_S` 同步，假设线上错误来自归约结果尚未对标量读取路径可见。该候选只改变归约结果到标量读取之间的同步方式。

## Scope

- 只实现 `MIX-B-DIRECT-FP32-NUMERIC`。
- 保持 FP32 中间计算、RMS、Sqrt、向量除法和 `CAST_ROUND` 输出路径。
- 保持 D004 的 32B 尾块补零搬入。
- 本候选只进行 server3 CANN 编译，不进行本地 NPU 正确性、profiling 或 benchmark。

## Compile target

- CANN: 服务器项目内 `cann-9.0.0` 工具链
- SoC compile flag: `dav-2201`
- Compile-only acceptance: `compile PASS`
