# B001 Task

## Route

True 2D Panel DMA and Broadcast on DAV_2201.

## Required architecture

- 二维 panel `[panelRows, D]` 是基本计算单位。
- UB 必须使用真实二维 row-major layout，不能只是 row 循环的外层包装。
- DMA 必须按 panel 组织，多行输入和输出使用 panel-level 搬运。
- gamma/bias 在 panel 内广播复用。
- reduction 必须体现多行调度，不能退化为 A001 式单行主循环。
- 所有队列、双缓冲、临时 tensor、reduction workspace 和对齐损耗计入 184 KiB 工作区预算。

如果最终控制流只是独立逐行 load/reduce/store，视为架构碰撞，不得提交为 B001。

## Required full-domain behavior

实现 hot path 和 private generic fallback。必须覆盖 FP16、BF16、FP32、2D/3D/4D、D=64..32768、D 非 32B 对齐、tail rows、NaN/Inf 和任意合法 epsilon。

fallback 只负责正确性和完整覆盖，不进行性能调优，不复制其它候选代码。

## Required metadata

生成 `phase4/workspaces/B001/architecture-metadata.md`，记录完整 metadata 字段，包括二维 UB 布局、panel DMA、参数广播方式和多行 reduction 调度。

## Compile workflow

在自己的 workspace 从空白建立源码和 build 文件，使用 server3 的 `Ascend910B3` / `dav-2201` 工具链。CompileFix 只能处理编译兼容问题。Compile PASS 后停止源码修改并返回 Main 所需 metadata。
