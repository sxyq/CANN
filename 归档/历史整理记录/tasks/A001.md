# A001 Task

## Route

Row-Resident Fused Streaming on DAV_2201.

## Required architecture

- 连续 row range 分配给 Vector Core。
- 一个 Core 独占完整 row，不切分 D。
- UB 使用一维 row slots，所有 TQue、双缓冲、临时 tensor、reduction workspace 和对齐损耗计入 184 KiB 工作区预算。
- 参数在 row-owner residency group 内复用。
- reduction 在 Core 内完成，禁止引入跨核 reduction。

## Required full-domain behavior

实现 hot path 和 private generic fallback。必须覆盖 FP16、BF16、FP32、2D/3D/4D、D=64..32768、D 非 32B 对齐、tail rows、NaN/Inf 和任意合法 epsilon。

fallback 只负责正确性和完整覆盖，不进行性能调优，不复制其它候选代码。
