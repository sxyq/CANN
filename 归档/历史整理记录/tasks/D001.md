# D001 Task

## Route

Persistent Channel-Stripe Sweep on DAV_2201.

## Required architecture

- 固定 D stripe 映射到 Vector Core。
- 每个 Core 跨多个 row batch 持久处理自己的 stripe。
- gamma/bias 以 stripe 为单位长期复用。
- reduction 必须形成跨 stripe 的 row scalar 合并阶段。
- workspace、usedCores、blockDim 和同步次数必须在 metadata 中给出。
- CANN 8.5.0.alpha002 / Ascend910B3 / DAV_2201 的跨核 API、函数签名、Kernel 限制和 workspace 要求必须由 Child 在实际编译环境确认。
- 不预先规定使用哪一个跨核 API；Child 自行选择并记录理由。
- 所有队列、双缓冲、临时 tensor、reduction workspace 和对齐损耗计入 184 KiB 工作区预算。

任何同步点都必须保证所有参与 block 按相同顺序和次数执行。没有有效数据的 Core 也必须按照设计参与同步，或由 host 侧把 blockDim 缩到实际参与数。

## Required full-domain behavior

实现 hot path 和 private generic fallback。必须覆盖 FP16、BF16、FP32、2D/3D/4D、D=64..32768、D 非 32B 对齐、tail rows、NaN/Inf 和任意合法 epsilon。

fallback 只负责正确性和完整覆盖，不进行性能调优，不复制其它候选代码。

## Required metadata

生成 `phase4/workspaces/D001/architecture-metadata.md`，记录 stripe residency lifetime、usedCores、blockDim、workspace、同步 API、同步次数以及所有规定字段。

## Compile workflow

在自己的 workspace 从空白建立源码和 build 文件，使用 server3 的 `Ascend910B3` / `dav-2201` 工具链。CompileFix 只能处理语法、类型、include、API signature、CMake/build 和目标平台兼容问题，不得改变跨核架构。
