# E001 Task

## Route

Primitive-Assisted RmsNorm on DAV_2201.

## Required architecture

- 先在 server3 实际 CANN 8.5.0.alpha002 / DAV_2201 环境验证 RmsNorm 高阶 API。
- 验证 dtype support、BF16 support、D 对齐要求、gamma 对齐要求和 temporary buffer requirements。
- 使用官方 RmsNorm tiling 接口获取实际临时区需求，不能假定最大临时区一定可用。
- residual add 在 RmsNorm 前，bias add 在 RmsNorm 后。
- 所有队列、双缓冲、临时 tensor、RmsNorm temporary、reduction workspace 和对齐损耗计入 184 KiB 工作区预算。

## Required full-domain behavior

实现 hot path 和 private generic fallback。API 不支持的 BF16、非对齐 D、超大 D、非法 API tile 和 tail rows 必须由 E001 自己的 fallback 覆盖。必须覆盖 FP16、BF16、FP32、2D/3D/4D、D=64..32768、NaN/Inf 和任意合法 epsilon。

fallback 只负责正确性和完整覆盖，不进行性能调优，不复制其它候选代码。

## Required metadata

生成 `phase4/workspaces/E001/architecture-metadata.md`，记录 API 验证结果、RmsNorm tiling、temporary buffer、parameter residency、hot path/fallback 条件以及所有规定字段。

## Compile workflow

在自己的 workspace 从空白建立源码和 build 文件，使用 server3 的 `Ascend910B3` / `dav-2201` 工具链。CompileFix 只能处理编译兼容问题。Compile PASS 后停止源码修改并返回 Main 所需 metadata。
