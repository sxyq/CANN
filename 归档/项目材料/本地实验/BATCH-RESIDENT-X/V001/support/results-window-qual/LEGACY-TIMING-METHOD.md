# LEGACY_TIMING_METHOD

Window-qual probes in this directory were produced by the legacy CPU wall-clock
harness (`timing_probe.asc`: steady_clock around launch+sync, warmup 5, 11–21
samples, process-per-rep, no device events). Method tag: LEGACY_TIMING_METHOD.

- Files tagged: `gates-summary.json`, `gate-d4.json`, `gate-d6.json`,
  `window-qual-handoff.txt`, `q-*.tsv`.
- Not comparable to DEVICE_EVENT numbers from the unified runner.
- Do not merge medians across methods.
- Data retained unchanged; see `../../LEGACY-TIMING-METHOD.md`.
