## 路线与版本

- phase3 的 R001–R029 路线思想，对应 FULL-R001–FULL-R029 实现系列；两者关系逐条记录在 `技术路线/技术路线总表.md`。PURE-R 系列、外部实现和旧 R029 保持各自来源。
- 外部 ChatGPT R029 V003/V004 位于 `phase3-before-reset-20260920/提交/外部轨道-ChatGPT编译并修复/源码/`，并单列为 `LEGACY-R029-WIDE-CACHED-ROW-EXTERNAL`；不要与 FULL-R029 合并。
- phase3 deep-exploration 的 R006、R017、MIX-A、MIX-B、R031 版本和结果分别链接到对应路线；汇总文件仍在 `phase3-before-reset-20260920/旧探索源码/deep-exploration/`。
- phase3 `MIX-A-D001..D003` 与比赛后期 `MIX-A` 分开；R031 原始实现与 `MULTIMODE-R031-RECONSTRUCTION` 也分开记录。
- phase3 混合路线 H001 与 phase4 Fresh Small-D 的 H001 分开保存。
- 比赛结束后 N01–N05 的新命名路线与旧名结果可从 `技术路线/路线主线/` 的同一路线入口查看；版本顺序仍按原记录分段阅读。
- 各版本目录沿用原编号。根目录的实验、结果和研究路径是指向 `比赛结束-20261017/项目材料/` 的兼容链接。
- 历史文件中已有的旧路径和用语保留原貌。具体路线关系、版本成绩及材料路径以 `技术路线/` 中的总表与结构化记录为准。

历史阶段快照、嵌入式路线 Git 克隆、实验数据、失败材料和用户文件均保持原位置；本归档说明不代表对源码作版本拼接。
