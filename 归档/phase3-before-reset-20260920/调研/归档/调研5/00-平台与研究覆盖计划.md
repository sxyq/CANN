三类代码形态（已逐一读取确认）：

1. **标准 Ascend C / msopgen 工程源码**：`源码/`（op_host + op_kernel + CMakeLists.txt + build.sh），入口为标准算子 `add_rms_norm_bias(GM_ADDR…, workspace, tiling)`，v1 正确性优先两遍扫描实现。
2. **CANNJudge 直调模板提交代码**：`提交/V001`、`提交/V002`（单文件 `kernel.asc`）；下载模板 `/Users/sunyiyang/Downloads/addrmsnormbias_problem_1742_template/`。**提交目标为直调模式**：`extern "C" void run_kernel(…, int64_t availableCoreNum, aclrtStream stream, float epsilon)`，内部 `<<<blocks, nullptr, stream>>>` 启动 `__global__ __vector__` 核函数；`TensorInfo.dtype` 枚举 **0=fp32 / 1=fp16 / 2=bf16**（与源码工程编码不同）；CMake 默认 `SOC_ARCH=dav-2201`；本地模板用例 FP16 [1,64]，判题容差 rtol=atol=tol=0.001。
3. **调研文档与记录**：`文档/`（题面分析含上轮调研2已固化结论）、`临时/api-pages/`（约 30 个官方 API 页面 HTML 缓存）、`临时/precision_probe*.py`。

关键历史事实：

- V002 一次平台提交"上传内容异常"（平台收到首行 `return false;`），未获得有效结果；当前 V002 为 2955 行候选，含宽行/缓存行/批处理/流水多路径。
- 上轮"调研2"的裁决已固化进 `文档/problem-add-rms-norm-bias.md`：`DataCopyPadExtParams` 字段顺序 `{isPad, leftPadding, rightPadding, paddingValue}`（A 级）；UB→GM 搬出 dummy 被丢弃不写相邻内存（A 级但保留真机首验项）；ReduceSum 无单一 count 硬上限（A 级，工程保守分块 ≤4096）。
- 上轮调研2文件已丢失（未提交 git），本轮负责在 `调研/调研2/` 重建并深化。

已知题目约束（A 级，官网题面）：y=x+residual；rms=sqrt(mean(y²,dim=-1)+eps)；output=y/rms*gamma+bias；fp16/bf16/fp32；2D/3D/4D；D∈[64,32768]；batch∈[1,8192]；seq∈[1,32768]；15 测试点全过才计分；单点得分 100/(1+log₁.₅(t/T))，性能为唯一计分维度，iterations=5；归约必须 FP32；核心计算必须进 Kernel。
