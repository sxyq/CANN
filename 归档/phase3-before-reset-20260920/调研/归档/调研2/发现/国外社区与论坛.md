# F5: 国外社区与论坛

## Findings

### [1] OpenAI 官方披露的多 Agent 科研编排方式：约 10,000 个并发 Agent 分成可组内通信的小组，按题面变体分组探索，用 Codex 汇总各组中间结果做交叉授粉
- quote: "We used a system of coordinating agents powered by our internal model. The agents had access to tools such as the ability to read from a cached version of the internet and the ability to run code. Agents were subdivided into groups with the ability to communicate within the group. The groups varied in size, and the group that produced the Navier–Stokes resolution involved on the order of 10,000 concurrent agents."
- url: https://openai.com/index/navier-stokes-solution/
- source_type: primary
- published: 2026-09-08
- confidence: high

### [2] OpenAI 的任务拆分策略：对每个 Millennium 问题用不同 Agent 组提示题面变体（A/B 为可证方向、C/D 为可否证方向），先攻"更容易"的 Euler 正则性问题，再把 Euler 结果注入 Navier–Stokes 组
- quote: "For each problem, we prompted different groups of agents with different variants of the problem statement, covering all variants of the problem. For the Navier–Stokes problem, we suggested versions \"A\" and \"B\" ... and versions \"C\" and \"D\" (which would result in a disproof) to separate groups of agents."
- url: https://openai.com/index/navier-stokes-solution/
- source_type: primary
- published: 2026-09-08
- confidence: high

### [3] 共享中间结果的具体机制：OpenAI 用 Codex 从各 Agent 组提炼最有用的洞见，再作为后续 prompt 交叉授粉；Navier–Stokes 解出组正是被这种方式引导
- quote: "After some time, we cross-pollinated the agent groups by using Codex to consolidate the most useful insights from each agent group. These follow-up prompts drew on the agents' own intermediate results. The group that found the solution to Navier–Stokes was guided in such a way."
- url: https://openai.com/index/navier-stokes-solution/
- source_type: primary
- published: 2026-09-08
- confidence: high

### [4] 规模与时长的官方数字：全部问题共 490 万条消息、约 3000 亿输出 token；Navier–Stokes 单题 270 万条消息、约 1300 亿输出 token；解出用时约 88 小时，Lean 形式化再花 17 小时（由 GPT-6 Astra 完成）；Euler 正则性反例由近 100 个 Agent 协作约 50 小时产出
- quote: "The agents arrived at their resolution on Saturday, September 5, about 88 hours after the first agents were launched. Lean formalization and verification took an additional 17 hours via GPT‑6 Astra. Across all attempted problems, the agents sent 4.9 million messages and used about 300 billion output tokens."
- url: https://openai.com/index/navier-stokes-solution/
- source_type: primary
- published: 2026-09-08
- confidence: high

### [5] Simon Willison 按 GPT-6 Astra 公开 API 价估算 3000 亿输出 token 约合 1500 万美元；HN 讨论中也出现 $15M–$22M 的量级估计，说明多 Agent 数学证明已进入"大科学"预算区间
- quote: "(We don't know the cost structure of the internal model they used, but 300 billion output tokens at public API prices for GPT-6 Astra would cost $15,000,000.)"
- url: https://simonwillison.net/2026/Sep/8/on-navier-stokes/

### [6] Buckmaster 声明：人类数学家 + 多 LLM 的一年期协作是另一种组织方式——用 Claude 与 Codex（GPT-5.6 Sol）主攻、Astra 只用于写稿与论证审计；8 月 15 日突破，8 月 22 日 Lean 验证完成
- quote: "We used several LLMs throughout: Anthropic's Claude, OpenAI's Codex, especially with GPT-5.6 Sol and, more recently, Astra. The latter was only used for writeups and auditing our arguments."

### [7] LLM 证明的典型失败模式（当事人原话）：首份 LLM 生成证明"是我读过最可怕的"；Euler 写稿"只能形容为 AI slop"；作者认为 Lean 证书不能替代可读的数学论证，因此故意不赶着发未打磨的预印本 + 证书
- quote: "I can say the first LLM generated proof Levent sent me was the most horrendous I have ever read; we verified it on Lean on August 22nd. ... The Euler writeup, in particular, can only be described as AI slop. ... I feel strongly that the first thing anyone reads should be a mathematical argument presented in the normal manner, rather than just a formal certificate."
- url: https://cims.nyu.edu/~tristanb/statement.pdf
- source_type: primary
- published: 2026-09-08
