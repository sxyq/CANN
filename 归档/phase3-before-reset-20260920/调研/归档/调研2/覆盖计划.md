## 2. 各代理执行规范与禁止红线

1. **唯一真相原则**：
   - 题面输入输出与评分规则以官方 API 和下载模板 `main.asc`/`verify_result.py` 为最高准则。
   - API 语义以 CANN 9.0 官方头文件及手册为准。
2. **严格禁止事项**：
   - 禁止在未登录真机环境前宣称“已编译通过”、“精度已达标”、“性能已达最优”。
   - 禁止调用 CANNJudge 真实上传接口或消耗比赛提交额度。
   - 禁止在代码、文档或日志中泄露任何凭据、Token、密码或个人隐私。
   - 禁止创建第二套工程目录或备份副本，所有调研文档统一下沉至 `调研/调研2/` 目录。
3. **交付成果要求**：
   - 每个子专题输出独立的 Markdown 文档，结构清晰，数据、代码片段、数学公式齐全。
   - 汇总生成系统性的技术方案调研总报告（包含 15 个必备章节）以及全量更新的来源清单 `sources.md`。
