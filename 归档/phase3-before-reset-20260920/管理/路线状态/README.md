# 路线状态 JSON（旧管理模型）

本目录的 `R001.json` … `R029.json` 属于**旧的 R001–R029 管理模型**，只作历史保留，不再代表当前工作状态。

## 使用前必读

- 这些 JSON 属于旧 R001–R029 管理模型，字段（`status`、`champion`、`next_action` 等）按当时的深度优先流程填写。
- `official_score=null` **不等于**线上没有结果。仓库与上游对话中已存在多条 15/15 与官方分记录（例如外部轨道 28.68 / 29.01，以及后续更高分），只是没有写进这些 JSON。
- 这些 JSON **不是**当前 FULL 广度优先主线的真相，不能据此判断某条路线「未开始」「无分数」或「下一步做什么」。
- 当前真相入口：[`文档/当前状态.md`](../../../文档/当前状态.md)。

## 编号命名说明

- 本目录的 `R029` = 官方 Tiling 五模式，旧模型语境下建议读作 `LEGACY-R029-TILING-FIVE-MODES`。
- 外部旧轨道的 `R029`（wide cached-y 计分线，`R029-V003` / `R029-V004`）**不等于** FULL 模型的 `FULL-R029-WIDE-CACHED-ROW`。同号不同代，分数、状态和源码都不能互相套用。
- 同理，外部旧 `R006/R013/R014/R016` 与 `FULL-R*` 也是不同代编号。

## 处理原则

- **不要删除**这些 JSON 文件。它们是旧管理模型的原始记录，删除会丢失编号与字段的历史语义。
- 需要当前状态时，一律改读 `文档/当前状态.md`、`文档/路线树.md`。

## 附：旧模型原文（历史保留，仅用于读懂现有 JSON）

每个 `Rxxx.json` 是一条路线的机器可读状态。`official_score` 只有在 CANNJudge 返回有效分数后才能填写；本地编译、NPU 运行和 profiler 数据只能放在 `local_reference`，不能代替官方分数。

状态含义：

- `PLANNED`：只有研究材料，尚未形成可验证版本。
- `EXPLORING`：已有版本或实验，但尚未完成官方分数驱动的性能收敛。
- `BLOCKED`：有明确阻塞（环境或流程），保留反例并等待修复/资源。
- `CONVERGED`：满足统一流程中的官方分数收敛判据。
- `REOPENED`：收敛后因新证据重新打开。

> 上述字段语义属于旧管理模型；与 `文档/当前状态.md` 冲突时，以 `文档/当前状态.md` 为准。
