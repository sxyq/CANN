# online — 线上结果快照

存放每次 CANNJudge 提交的结果快照，每份至少包含：

- submission id
- 状态（CompileError / Pass / WA / Runtime 等）
- 15 个 case 的逐点结果
- Official Score（只抄平台，不自行计算）
