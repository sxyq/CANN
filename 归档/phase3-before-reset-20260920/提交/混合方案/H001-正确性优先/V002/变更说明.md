# V002 变更说明

V002 现采用用户提供的完整 Ascend C 候选，保留题目入口和计算语义，并针对 `V001` 的平台编译信息统一使用 `tpipe` 标识符。

## 变更

- 导入用户提供的 2947 行候选，覆盖小行、整 tile、宽行、批处理和流水路径；加入尾块字段后当前文件为 2955 行。
- 将候选中的 `TPipe pipe_` 全部改为 `TPipe tpipe`，规避 `V001` 平台日志中的同名解析问题。
- 在统一 `Load` 入口中显式设置 `DataCopyPadExtParams<T>` 的尾块字段，右侧补齐元素为 0。
- 保留 FP32、FP16、BF16 三条计算路径，核心计算仍在 Ascend C Kernel 内完成。
- 保留最后一维展平、`uint64_t` 行寻址、`DataCopyPad` 尾块搬运、`ReduceSum` 和事件同步。
- 保留 gamma/bias 最后一维广播，并按输入类型执行输出转换。

## 候选来源

- 来源：用户在当前会话提供的完整代码文本。

- 只做了标识符替换和尾块参数具名设置；没有加入测试数据、固定输出或 Host 代算。
