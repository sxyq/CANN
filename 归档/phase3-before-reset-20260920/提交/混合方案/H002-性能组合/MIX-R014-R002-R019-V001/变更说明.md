## 代码 diff 要点

```cpp
// Parent
const float rmsValue = rms.GetValue(0);
Duplicate(residualFp32, rmsValue, valid);
Div(yFp32, yFp32, residualFp32, valid);

// Child（本版本）
const float invRms = 1.0f / rms.GetValue(0);
Muls(yFp32, yFp32, invRms, valid);
```

未改动：`kTileElems=8192`、R014 gamma/bias 驻留、R002 retained-y、ReduceSum、Sqrt、UB 布局、row/core 调度、输出 CAST_RINT。

## 静态审查（2026-09-16）

- API/UB 审查：无阻塞；双路径均已替换；与实验卡一致。
- 数值/生命周期审查：`yFp32` 在 normalize 前未被覆盖；gamma/bias cache 与行 Load 上界不重叠；`residualFp32` 作 ReduceSum work 后无正确性依赖。
- `invRms` 相对 `Div` 的额外相对误差约 1 ulp FP32（~1e-7），远低于 FP16/BF16 输出量化步长。
