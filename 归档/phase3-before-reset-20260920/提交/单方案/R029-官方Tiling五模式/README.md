# R029 官方 Tiling 五模式

## 路线定位

本目录保存官方 RMSNorm 相关实现中的 `SPLIT_D`、`SINGLE_N`、`MERGE_N`、`MULTI_N`、`NORMAL` 五类分档，以及按 UB 容量反推 tile 的方法。它是运行时分档和 UB 预算参考，不等同于本题可以直接复用的 tiling 结构体。

## 与本题的迁移边界

可借鉴模式选择、D 分档、outer 分档和 UB 预算；本题是直调 `kernel.asc` 入口，不能直接依赖图模式的 tiling 结构体、自动生成参数或服务入图阶段的 workspace 约定。最终实现需要在 Kernel 内根据题面元数据推导安全参数。
