## 这是什么

对话助手用 **CANNJudge 平台本身作为编译器与判题器**（本地只做静态检查，明示 `no local CANN compile claimed`），在 27 小时内推进了十余个单变量版本，并拿到官方有效分数：

```text
R029-V003-WIDE-BF16-CACHED   15/15 Pass   官方 Score 28.68   (2026-09-17 15:13:49)
R029-V004-WIDE-LOWP-CACHED   15/15 Pass   官方 Score 29.01   (2026-09-17 15:27:42)
```

这与本仓库 `调研/路线最高分.md` 记录的「无有效平台分」不一致；本目录就是那条轨道的代码与证据。

## 使用边界

- 本目录**不是**本仓库验证过的提交候选：所有编译与精度结论都来自对话中的平台判题回贴，未经服务器 3 复核。
- 每个版本目录里的 `kernel.txt` 是按本仓库约定保存的本机形态；提交到平台或同步到服务器时必须原样改名为 `kernel.asc`。
- **路线编号未做归并**：本轨道里 `R029` 指「运行时分档 / 宽行 cached-y」，而仓库 `提交/单方案/R029-官方Tiling五模式/` 指官方五模式分档；两者同号异义。归并方案（改号或映射）待确认后再执行，此处保持对话原编号。
- **提交身份未闭环**：对话只提供了 Pass、官方分数和提交时间，没有 `submission_id`。按本仓库「分数必须绑定不可变提交身份」的规则，29.01 目前只是外部证据。
- 同名 `MIX-R014-R002-R019-V001` 在本仓库另有一份 459 行的副本（`提交/混合方案/H002-性能组合/`），与本目录的 1414 行版本不是同一份代码，详见审查报告 §0.3。
